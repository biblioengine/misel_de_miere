# Misel de Mière（ミセル・ド・ミエール）

眼鏡の処方値を入れると、裸眼でどう見えているかを映像で再現するジョークアプリです。

## 使い方

- 表の数値（球面 S・円柱 C・軸 AX）の ↕ を押さえたまま上下に動かして、度数を合わせます。
- 「露出」のスライダーで周りの明るさ（瞳孔の大きさ）を変えます。暗いほどぼけと光のにじみが大きくなります。
- 「Sample」の Day / Twilight / Night で映像を切り替えます。「Load file」から自分の写真や動画も使えます。読み込むときに、四隅をドラッグして使う範囲を決めたり、「90°」で向きを変えたりできます。
- 映像をダブルタップすると、その場所を注視します。視野が狭まってピントと視線が集まり、もう一度ダブルタップすると元に戻ります。
- 右下の「original」を押している間は元の映像に戻ります。

## 仕組み

- WebGL で、映像の各フレームを楕円形の点像（ぼけの形）でぼかしています。
- ぼけの大きさは「瞳孔径 × 度数」で近似し、乱視は軸方向の経線を S、直交する経線を S + C として楕円にしています。
- 画面の横幅を視野 60° として換算しています。
- 描画は 24fps です。

## 注意

見え方を楽しむためのエンタメアプリで、医療用の診断ツールではありません。目のことは眼科で相談してください。

## ファイル構成

```
index.html        アプリ本体（1ファイル）
assets/logo.png   ロゴ（星を除いた部分）
assets/stars.png  ロゴの三つ星
assets/day.mp4    サンプル映像 Day
assets/twilight.mp4  サンプル映像 Twilight
assets/night.mp4  サンプル映像 Night
```

サンプル映像はすべて作者が撮影したものです。
